# Stopwatch — Expo SDK 51

A native React Native stopwatch app built with JavaScript and Expo Router.

## Stack
- Expo SDK 51 (`expo ~51.0.0`)
- React Native `0.74.5`
- React `18.2.0`
- Expo Router `~3.5.23`
- JavaScript (`.js` / `.jsx`), no TypeScript

## Features
- Start, pause, and reset the stopwatch
- Centisecond display
- Record lap times and total elapsed times
- Best and slowest lap indicators
- Dark interface with Arabic RTL-friendly labels

## Run
```bash
npm install
npx expo start
```

Open the project with Expo Go. For a clean dependency install, use Node.js LTS and npm.
